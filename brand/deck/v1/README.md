# Praxis deck v1 (editable)

`praxis-deck.pptx` is a 10-slide 16:9 PowerPoint deck in the Praxis brand. Everything except the photos, the logo
and the progress marks is a native, editable shape: titles, stat numbers, HUD chips and cards, target outlines,
leader lines, every box and arrow in the architecture diagram, and both charts. Each slide has speaker notes.

## Before opening it

Install the five fonts in `fonts/` (double-click each `.ttf` → Install). PowerPoint looks for them by these names:
`Archivo Expanded SemiBold` (headings), `Archivo` and `Archivo SemiBold` (body), `IBM Plex Mono` (labels). They are
static cuts of the open-source Archivo and IBM Plex Mono fonts (SIL Open Font License, see `fonts/OFL-*.txt`).
Without them, PowerPoint substitutes another font and the headlines will look different.

## Editing

**In PowerPoint:** edit anything directly. Shapes have names (Selection Pane), for example `hud-chip-text`,
`hud-card-text`, `hud-target`, `hud-leader`, `box-state-tracker`, `arrow-tracker-verifier`, `stat-1`,
`chart-accuracy`, `footer-source`. Theme colors are set (Graphite, Plate, Steel, Aluminum, Torque Orange,
Torque Ink, plus green, blue and red for product states), so the theme color picker shows the brand palette.

**With Claude, two ways:**
1. Edit the `.pptx` itself (unzip, edit `ppt/slides/slideN.xml`, zip). Fine for wording changes.
2. Edit `build-deck.js` and rebuild. Better for layout changes or new slides, because the HUD helpers
   (`hudChip`, `hudCard`, `hudRegion`, `hudLeader`, `hudProgress`, `hudPulse`) and the diagram `box()` helper keep
   everything consistent. Photo-slide coordinates are in the 1920×1080 pixels of the HUD mocks
   (`px / 144` = inches).

```bash
cd brand/deck/v1 && npm install && node build-deck.js praxis-deck.pptx
```

## Assets

`assets/` is generated by `brand/src/assets.py`: the photos are desaturated and veiled in graphite outside the
target region (the spotlight), and the progress marks and grid background are rendered from the logo geometry.
The source photos are free Unsplash images; credits are in `brand/mocks/CREDITS.md`.

## Claims

Photo slides show concept mocks on stock photos and carry a "Concept mock · stock photo" tag. All numbers come
from `results/RESULTS.md` and `docs/CLAIMS.md`. They were measured on a public first-person cooking dataset, so keep
cooking footage off the slides and say so if asked. The glasses adapter is not tested on hardware yet.
