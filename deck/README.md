# Deck

`Praxis_SAH_Oct2026.pptx` is the Startups @ Harvard grant deck: 11 core slides (about 7 minutes) plus a 12-slide appendix, in the Praxis
brand (`brand/BRAND.md`). It's built by `build_deck.js`, so edit the script, not the .pptx. If you edit the .pptx in
PowerPoint, the next build overwrites your changes.

```bash
cd deck && npm install --cache "$TMPDIR/npm-cache" && node build_deck.js
```

- **Brand.** The cover, architecture diagram and closing cover use the same layouts, helpers and assets as
  `brand/deck/build-deck.js`; the assets are read from `brand/deck/v1/assets/`. The other slides are new, built in the
  same system: Aluminum background, Archivo / IBM Plex Mono type, rules, dark panels, and Torque Orange only for
  "ours" and the current step.
- **Fonts.** Install the five fonts in `brand/deck/v1/fonts/` before opening the deck (see `brand/deck/v1/README.md`).
  Without them, PowerPoint substitutes another font.
- **Order.** Each slide is a function. The runner at the bottom of `build_deck.js` sets the order and sections, and
  numbers the progress marks and appendix labels.
- **Progress marks.** Footer marks show slide n of 11. They're generated by `python3 deck/make_marks.py 11` (needs
  `rsvg-convert`). If the core count changes, regenerate them and update `TOTAL`; the build throws if they disagree.
- **Numbers.** Every number on a slide comes from `results/` (see `docs/CLAIMS.md`) or a cited source in
  `docs/POSITIONING.md` / `docs/VISION.md`.
- **Learning curves.** The learning-curve charts read `results/scaling/learning_curve.json`, which comes from
  `python -m praxis.eval.learning_curve` (run in `prototype/`; local, $0).
- **Photos.** The photo slides are concept mocks on stock photos and are tagged that way. No cooking footage is used
  on any slide.
- **Speaker notes.** Each slide's notes give the absolute numbers and the honest caveats.
- **Preview.** `Praxis_SAH_Oct2026.pdf` is rendered from the .pptx with the brand fonts (LibreOffice). Re-render it after every rebuild.
  Point LibreOffice at the fonts through a fontconfig file, or it silently substitutes Linux Libertine. Check with
  `pdffonts` that only Archivo is embedded (plus OpenSymbol for bullets):

  ```bash
  FONTCONFIG_FILE=/path/to/fonts.conf soffice --headless --convert-to pdf Praxis_SAH_Oct2026.pptx
  ```

  where `fonts.conf` lists `<dir>` entries for `brand/deck/v1/fonts` and `~/Library/Fonts`.
- **Versions.** Rendered snapshots live in `brand/deck/v2.5/`, `v2.6/`, `v2.7/` and later versions beside them. Each has a `CHANGES.md`.
